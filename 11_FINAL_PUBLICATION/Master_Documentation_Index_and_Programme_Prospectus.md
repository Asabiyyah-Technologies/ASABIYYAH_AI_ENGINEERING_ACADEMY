## 2. Official Programme Prospectus (Publication-Ready Candidate)

### ASABIYYAH TECHNOLOGIES LTD
### GLOBAL APPLIED AI ENGINEERING MASTERCLASS
**One Foundation. Multiple Specialisations. Real-World AI Products.**

#### 2.1 Why This Masterclass Exists
Modern organisations do not need more fragile prompt scripts or isolated notebook demos—they need **Applied AI Systems Engineers** who can integrate foundation and open-weight models into reliable, evaluated, security-verified software products. The **Asabiyyah Technologies Global Applied AI Engineering Masterclass** is a 14-week, intensive part-time engineering programme designed for software-literate practitioners in Nigeria, Africa, and globally.

#### 2.2 Key Programme Facts (Verified Baseline)
- **Duration & Workload:** 14 weeks, part-time (`12–15 learner hours/week`; `~192 total hours` across Live Instruction `4 h/wk`, Guided Labs `3 h/wk`, Independent Study `1.5–2.5 h/wk`, and Project Delivery `3.5–5.0 h/wk`).
- **Delivery Format:** Online-first, live instructor-led international cohort in English (maximum 50 learners in Cohort 1), supported by 1:6–7 Mentor Pods, downloadable low-bandwidth session packs (`<60 MB`), and offline-capable labs.
- **Hardware Accessibility:** Runs on standard CPU laptops (**8 GB RAM minimum** / **16 GB RAM recommended**, 25–50 GB SSD). **No dedicated GPU or paid API subscription is required.**
- **Entry Baseline:** Elementary Python proficiency (variables, loops, functions, dicts/lists), basic command-line/Git familiarity, and basic mathematical reasoning. *(Includes a free, optional 2-week self-paced Preparatory Pathway of 10–15 hours for applicants who need to consolidate their Python, Git, and API skills before Week 1.)*

#### 2.3 The 14-Week Engineering Journey
1. **Weeks 1–4 — Shared Common Core (`48–60 hours`):**
   Master production Python 3.11+, `Pydantic v2` schema validation, asynchronous `FastAPI` services, `pytest`, a provider-independent `ModelProviderAdapter` (`Ollama` local GGUF + remote APIs), golden dataset evaluation & OpenTelemetry GenAI tracing (`CD-01`), and foundational OWASP AISVS 1.0 & NDPA 2023 privacy controls (`CD-02`).
2. **Weeks 5–10 — Deep Specialist Track (`72–90 hours` — Choose ONE Track):**
   - **Track 1: AI Application Engineering** — Multi-provider failover gateways, tenant-isolated SQLite semantic/exact caching, stateful tool calling, real-time `SSE` streaming UIs, RBAC, LLM10 token rate limiting, and CI regression evaluation.
   - **Track 2: RAG & Knowledge Engineering (`CD-04`)** — Structure-aware document ingestion, `BM25` lexical search, dense embeddings, **Hybrid Retrieval via Reciprocal Rank Fusion (`RRF`)**, cross-encoder reranking, query transformation, metadata ACL pushdown (`AISVS C8`), and a 4-way comparative retrieval benchmark on a defined test dataset.
   - **Track 3: Agentic AI Engineering (`CD-03`)** — Pure Python ReAct loops, `LangGraph` stateful checkpointing & Human-in-the-Loop approval gates, practical **Model Context Protocol (`MCP`)** server and client implementation (`Tools`, `Resources`, `Prompts`, OAuth 2.1 permissions, `2026-07-28` stateless discovery), and `AISVS C9/C10` sandboxing.
   - **Track 4: Edge & Offline AI Engineering (`CD-05`)** — Open-weight models, `GGUF` quantisation (`Q4_K_M`, `Q8_0`), KV-cache and CPU thread tuning in `llama.cpp`/`Ollama`, embedded offline SQLite RAG & delta sync, `SHA-256` supply-chain checks (`AISVS C3/C6`), and a **Reproducible Edge AI Benchmark Report** comparing $\ge 2$ configurations under identical host conditions.
3. **Weeks 11–12 — Cross-Functional Integration & Product Engineering (`24–30 hours`):**
   Work inside a 10-person cross-functional product team combining specialists from all four tracks under unified `Pydantic`/`MCP` contracts and end-to-end OpenTelemetry tracing.
4. **Weeks 13–14 — Production Hardening, Security Verification & Capstone Defence (`24–30 hours`):**
   Execute cross-team red-teaming, author your **AI System Evaluation Report (`CD-01`)** and **OWASP AISVS 1.0 Security Verification Report (`CD-02`)**, and complete a **15-minute Individual Oral Technical Defence**.

#### 2.4 Certification & Honest Representation (`PR-01`)
Graduates who pass all four assessment gates ($\ge 70\%$ overall weighted score, all mandatory `CD-01..05` reports, and the Individual Oral Technical Defence) are awarded the **Certificate of Completion in Applied AI Engineering (with named Specialisation Track)** issued by **Asabiyyah Technologies Ltd**.
*(Transparency Notice: This Certificate of Completion is an industry-oriented corporate training credential issued by Asabiyyah Technologies Ltd. It is not a university degree, statutory professional licence, or externally accredited certificate, and using OWASP AISVS 1.0 as a capstone verification standard does not constitute formal certification or an independent security audit.)*
